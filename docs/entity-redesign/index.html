Entity GUI — Redesign Mockups

Three distinct, interactive directions for the Advanced → Entity screen.

Each mockup is a self-contained, clickable prototype with the same shared mock data, so you can sample the actual workflow — merge a suggested duplicate, add an alias, split two entities, disambiguate a colliding term, and watch the decisions ledger update. All three are mobile-first (rendered inside a phone frame), match the chat-view aesthetic, and went through an adversarial red-team pass for UI fidelity, usability, and functional completeness.
  • Balanced goals: each supports both curation (merge/split/alias) and exploration (browse/relationships).
  • Reimagined broadly: they surface things today's screen doesn't — AI merge suggestions, ambiguous-term disambiguation, co-mentions, and medical/calendar cross-links.
  • Cross-navigation (open a note / KB article / medical record) is a toast stub; all core entity operations genuinely mutate state.
01

Triage Inbox

curation-forward

An actionable feed of entity-health issues — AI-suggested merges (with confidence), ambiguous terms, and self-reference folds — resolved in 1–2 taps, over a full Browse roster and a History ledger. Aims for “inbox zero” on entity hygiene.
